## Featured Project

### [FC Emerald Gang Web Portal](https://github.com/Mar1kya/fc-web-portal)
A full-stack bilingual web portal for a football club, featuring a public interface, an integrated fanshop, and a role-based admin dashboard.

* **Live app:** [fc-web-portal.vercel.app](https://fc-web-portal.vercel.app)
* **Key Features:**
  * **Frontend & UI:** Developed a responsive, SEO-friendly interface built with Next.js 16 (App Router), React 19, and Tailwind CSS v4.
  * **E-commerce Fanshop:** Built with a persistent cart (Zustand) and Stripe integration. Features a smart checkout that seamlessly links guest orders to new Google OAuth accounts.
  * **Dynamic Match Center:** Engineered utilizing the Sofascore API via RapidAPI. Implemented scheduled Vercel cron jobs and on-demand admin triggers to sync match details, rosters, and standings.
  * **Administrative Dashboard:** Designed a role-based panel using Prisma ORM and PostgreSQL. Provides comprehensive content management, advanced data grids (TanStack Table), sales analytics (Recharts), and low-stock monitoring.
